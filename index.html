FantasyDraftTool (working title)

FantasyDraftTool is a pre-launch fantasy football web application exploring draft preparation, connected-league intelligence, roster analysis, waiver/FAAB strategy, historical league analysis, and in-season decision support.

Draft preparation

League-aware rankings, projections, ADP, player research, schedule analysis, risk and range-of-outcomes tools.

Connected leagues

Planned support for securely connecting fantasy leagues so analysis can reflect each league's real scoring, roster construction, standings and activity.

In-season intelligence

Planned roster, matchup, waiver, FAAB and league-history tools built from read-only league data.

Current status: FantasyDraftTool is in private development and testing. A public consumer launch may be pursued in the future if development is successful.

Yahoo Fantasy integration

Yahoo Fantasy Football is planned as the first connected-league platform. Users will authorize read-only Yahoo Fantasy Sports API access through Yahoo OAuth. FantasyDraftTool will not submit roster changes, waiver claims, trades, draft picks or other write actions to Yahoo.

Fantasy data provided by Yahoo Fantasy where applicable.
